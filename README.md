# Sign-FE

**The Most Affordable DocuSign Alternative**  
Professional document signing at a fraction of the cost. Get all the features you need without the premium price tag.

🌐 **Live Demo**: [sign-fe.vercel.app](https://sign-fe.vercel.app)

---

## 📜 Overview
Sign-FE is a lightweight and affordable e-signature web application that allows users to sign and manage documents securely—without paying for expensive enterprise tools.  
Built with modern web technologies for speed, scalability, and ease of use.

---

## ✨ Features
- ✅ Upload and sign documents digitally
- ✅ Secure and reliable signing process
- ✅ User-friendly interface with responsive design
- ✅ Lightning-fast frontend powered by Vite & React
- ✅ Deployed on Vercel for seamless scalability

---

## 🚀 Getting Started

### Prerequisites
- **Node.js** (>= 16)
- **npm** or **yarn**

### Installation
```bash
# Clone the repository
git clone https://github.com/Jeelislive/sign-fe.git

# Navigate to the project
cd sign-fe

# Install dependencies
npm install

Development
npm run dev

Runs the app in development mode.
Open http://localhost:5173
 to view it in the browser.
